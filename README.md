# FitNES

Personal, offline-first PWA workout tracker built with Solid.js and TypeScript.

## Product and agent context

Start with [the vision](docs/vision.md) and
[product decisions](docs/product-decisions.md). The
[repository map](docs/repo-status.md) explains the temporary preview and existing
experiments; the [backlog](docs/backlog.md) proposes the integration order.
Coding agents must also follow [AGENTS.md](AGENTS.md).

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
