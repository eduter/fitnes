FitNES / Input study 04

Fixed slots. Game-style number entry.

Three popovers, one fixed mask. Compact stacked spinners handle small changes; each exercise keeps its own weight increment.

Compare Digit grid Number pad Digit spinners

Try it: tap a number to open its picker. Select a digit slot, then replace it; DONE closes the picker. Small changes use the compact up/down pair. MORE lets you configure the weight increment or switch between barbell, dumbbell and cable examples. Each exercise remembers its own increment on this device.

The workout screens use a 256-pixel canvas, the approved steel frame, the home artwork’s material colors, and true lowercase Pixel Operator glyphs. Screens scale to whole device pixels. The explanatory page is outside the NES screen.

This is an isolated demo with sample workouts. Only demo weight increments persist; it never opens your workout database. No numerical control uses a text input, so the system keyboard stays closed. Keyboard navigation, named buttons and a dialog focus loop remain available.
