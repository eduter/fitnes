# Earlier wide basement study

Retained for material and tile reference. Its upright door facades and tall wall
faces were rejected in favor of the thin top-view composition on black.

`map.json` preserves the original indexed pixels. The native 8×8 tile atlas,
placement data and checked sample are rebuilt with `npm run art:corridor`.

See the [reference package](../../README.md) for the owner's decisions, shared
sprites, alternative sheets and verification instructions.
