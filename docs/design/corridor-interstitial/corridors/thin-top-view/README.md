# Preferred thin top-view corridor

DW3 framing: a 32-pixel walking lane, 8-pixel wall caps on either side and pure
black outside. The native source is `layout.json`; `map.json`, the PNGs and tile
atlas are rebuilt with `npm run art:corridor`.

See the [reference package](../../README.md) for the owner's decisions, shared
sprites, alternative character sheets, tile format, proof instructions and
deferred implementation status.
